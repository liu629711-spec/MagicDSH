# 对标 3099 基线（能力对表）

**判据一句话：需求来自 3099，实现优先来自底座。** 官方已有的就用官方，并在同一轮退役被替代的那份 ——
绝不两套并存（两套 `browser_*` 并存导致模型随机选择，是已付过的学费，见 `决策记录.md` 2026-09-13）。

结论只有四个值：

| 值 | 含义 |
| --- | --- |
| **用官方** | 底座已有对应实现，退役我们/vendored 的那份 |
| **留自研** | 底座没有，或明确不开放（如跨包 import 组件） |
| **退场** | 本版不做，且不留残挂（清空即删 `legacy-vendored.patch.yml` 对应条目） |
| **新建** | 3099 有、底座没有、我们也没有 —— 本版要做的增量 |

`PT` = `OLD/patches/web.patch.yml`（3099 的挂载清单）。置信：**H** = 清单或源码直接支持；
